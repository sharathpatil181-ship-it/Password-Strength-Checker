# 🔐 Password Strength Checker

## 📌 Project Overview

The Password Strength Checker is a simple application that validates whether a password meets standard security requirements. The project is available in both a Python console version and a web-based version built using HTML, CSS, and JavaScript.

It checks passwords in real-time and provides feedback based on commonly accepted password security rules.

---

## 🎯 Project Objective

- Build a password validation system using regular expressions and conditional statements.
- Improve password security awareness.
- Provide instant feedback on password strength.
- Learn frontend and Python programming concepts through a practical project.

---

## 🚀 Features

- Checks minimum password length.
- Verifies at least one uppercase letter.
- Verifies at least one lowercase letter.
- Verifies at least one numeric digit.
- Verifies at least one special character.
- Real-time validation in the web application.
- User-friendly interface.
- Console-based password checker in Python.

## 🧠 How It Works

1. User enters a password.
2. The application checks each validation rule.
3. Failed conditions are displayed immediately.
4. If every condition is satisfied, the password is marked as **Strong**.
